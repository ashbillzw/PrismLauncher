# 本地安装测试

2026-10-30。本机 C 盘构建，沿用 `niijima` preset。缺少测试配置即使用正式网络流程。

程序旁可放 `niijima-local-test.json`：

```json
{
  "pack": "C:/mydata/Repositories/niijima-railways-modpack/build/pack-test.zip",
  "mirror": "C:/mydata/Agents/Codex-CreateTrainResync/prism-local-test/mirror/niijima-mirror"
}
```

相对路径按该配置所在目录解析。`mirror` 内直接包含 `assets/`、`files/`、`meta/`。配置缺失时不启用；存在但无效时，首页安装报错，不改用远端包。修改配置后重新启动程序。

本地 pack 复用 `InstanceImportTask` 的文件导入入口。镜像 GET/HEAD 通过 Qt 网络管理器映射为本地 file URL，仍使用原来的下载、缓存和哈希校验流程；缺少镜像文件不会回退 HTTP。测试模式临时采用新岛元数据和资源入口，不将本地路径保存到正式 `niijimalauncher.cfg`。

这是整合包、Minecraft/Forge/LWJGL 与 assets 的本地安装替代，并非全程序断网模式。账号登录、Java 自动下载、新闻等仍保留原行为；请使用已有 Java 17。测试包已展开全部索引文件，因此安装本包无需下载这些文件。其他版本若不在镜像内会失败。

**正式发行前删除程序旁的 `niijima-local-test.json`。** 此文件已忽略，不提交。现有安装器打包白名单会拒绝这个额外 JSON，不能随测试配置发行。程序目录与独立测试 profile 分开；无需修改用户现有 Prism/PCL 实例。

使用 `https://mc1.ashbill.com:25572/synology-root/minecraft/niijima-launcher/`，镜像在 `niijima-mirror/`，包索引在 `packs/latest.json`。

通过自研共享终端只读核对 `/etc/nginx/conf.d/minecraft-backup.conf`：已有 `mc1.ashbill.com` 的 25572 TLS 站点及 `/synology-root` → `/synology/MCShare` 映射。镜像根索引实际 HTTP 200，无需新增 nginx 路由。

镜像 7 个 JSON 内的 174 个绝对 URL 也必须更新；组件版本 → 组件索引 → 根索引的 SHA-256 逐层重算。不能仅替换启动器默认根地址。本轮本地元数据已更新，远端状态及构建结果见 handoff 最新记录。此记录不代表正式包索引或 ZIP 已上传。
