# 启动器错误码

仅在正常使用中不应发生的内部或发行数据异常时，首页、渠道或迁移窗口显示 `发生了错误（错误码：XXXX）`。在启动器数据目录的 `logs/NiijimaLauncher-0.log` 搜索 `Niijima error XXXX` 可查具体原因。首页后台检查失败时只记日志。

| 错误码 | 原因 |
|---|---|
| 1001 | 发布索引地址无效。需有效的 HTTPS 地址，本机回环测试也支持 HTTP。 |
| 1002 | 发布索引 JSON 解析失败。日志附解析器报告的原因。 |
| 1003 | 发布索引的根节点不是非空 JSON 对象。 |
| 1004 | 索引中的渠道不存在、记录类型无效，或已登记 CDK 的渠道映射损坏。 |
| 1005 | 请求的渠道或已登记 CDK 对应的渠道没有发行包。兑换时保留当前渠道。 |
| 1006 | 指定的 pack-id 或版本记录的键不是合法编号。日志区分十进制格式、零或前导零、整数溢出。 |
| 1007 | pack-id 对应的版本记录不是对象。 |
| 1008 | 版本记录缺少非空的 version 字符串。 |
| 1009 | 版本记录的 file 不是有效的单个包文件名。 |
| 1010 | 索引中没有指定的 pack-id。 |
| 1011 | 发布索引返回 HTTP 4xx／5xx（407、408、429 除外）。连接、代理、超时或限流等暂时失败提示重试。 |
| 2001 | 历史编号。现在无法打开本地测试配置时显示「无法读取本地测试配置，或配置不正确。」路径及系统错误写入日志。 |
| 2002 | 本地测试配置 JSON 损坏或根节点类型错误。目录未配置或不完整时提示「无法读取本地测试配置，或配置不正确。」 |
| 3001 | 安装后校验 pack-id 时找不到目标实例。 |
| 3002 | 新岛包标记缺失或无效、编号为零，或标记中已有不匹配的编号。 |
| 3003 | 已安装包标记中的渠道与本次发行渠道不一致。 |
| 3004 | 历史编号，旧启动器写入安装标记失败。当前仅校验标记，无写入分支。 |
| 4001 | 缺少迁移规则，规则类型、路径不合法，或重复写同一目标。 |
| 4002 | 所选旧版本或渠道与 pack-id 没有匹配的默认配置，或声明的基准文件缺失、路径无效。 |
| 4003 | 新实例中缺少迁移规则声明的目标文件。 |
| 4004 | 已识别 pack-id 的迁移源在执行时缺少已选的设置文件，或文件指向源目录外。手选和自动选择共用此编号。 |
| 5001 | 发行 ZIP 本身无法解析、条目损坏、路径越界，或缺少 Modrinth 清单。 |
| 5002 | 发行包内 Modrinth 清单 JSON、字段、依赖或文件下载定义无效。 |
| 5003 | 发行索引指定的 ZIP URL 返回 HTTP 4xx／5xx（407、408、429 除外）。 |
| 5004 | 新岛包安装任务失败，未能归类。上游失败详情写入启动器日志。 |

判定时假设启动器、发行包和发布配置均正确。此时玩家操作或本机环境仍可能引起的失败，使用审核过的提示。启动器提供的旧版本选项以及发行过的来源 pack-id 都应有对应基准。有效 CDK 应指向已有发行包的渠道。违反这些约定时使用错误码，由维护者处理。

| 位置 | 触发条件 | 玩家看到的文字 |
|---|---|---|
| 迁移窗口 | 选到当前实例 | 请选择迁移源版本文件夹 |
| 迁移窗口 | 无有效 pack-id 的旧版目录缺少声明文件，或实际读写失败 | 无法读取或写入配置文件 |
| 迁移窗口 | 游戏正在启动或运行 | 请关闭游戏再迁移 |
| 安装失败弹窗 | 确认下载连接失败 | 下载失败，请检查网络后重试 |
| 安装失败弹窗 | 确认安装文件或目录读写失败 | 无法读取或写入安装文件 |
| 安装失败弹窗 | 上游任务未区分失败原因 | 发生了错误（错误码：5004） |
| 渠道窗口 | 输入的 CDK 未登记 | cdk无效 |
| 下载或渠道窗口 | 连接、代理、超时或限流导致远程索引暂时不可用 | 无法获取版本列表，请检查网络后重试 |

手选目录优先识别有效 pack-id。手动和自动选源均按清单逐项检查，存在者默认勾选，缺项置灰；全部缺失时显示已有读取错误。无编号时仅勾选需要旧版基线的项目才显示版本选择器。日志记录失败文件或缺失基准的版本信息。

新增或调整错误分支时，在同一改动中维护此表。已分配的错误码保留原含义。用户可以直接纠正的输入提示（如 `cdk无效`）沿用已确认的文案。
