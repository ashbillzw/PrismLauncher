## 当前实现

`launcher/ui/NiijimaHomeWindow.{h,cpp}` 新增圆角开屏，2026-10-29 按用户确认使用确定版背景并叠加磨砂玻璃效果，主色 `#f39801`，标题「新島鉄道」使用内置 Zen Maru Gothic Bold。字体和授权文件在 `launcher/resources/niijima/`。顶部只有关闭按钮，下方按需出现安装进度条；首页常驻「下载游戏 / 启动游戏」「进入 Prism」两个按钮；按用户标注移除额外标题、宣传语、设置及选择已有实例入口，仅保留英文标识。

下载调用原 `InstanceImportTask` 和 `InstanceList::wrapInstanceTask`；只给实例提交成功处增加带任务身份的通知，记录该任务实际提交的实例 ID。没有按中文显示名猜测实例，也没有另写下载器。本页导入后自动记录实例；保留已有绑定，多条已绑定实例仍可切换。其他实例通过原 Prism 管理，不再提供首页手动绑定按钮。启动调用原 `Application::launch`，登录和 Java 处理继续走 Prism。

下载进度沿用原任务信号；速度和 ETA 取原请求提供的当前文件数据，不冒充整个安装的总 ETA。原流程预下载游戏文件失败后仍可能导入成功，所以完成文案是「实例已安装，启动时会检查并补齐运行文件」，不宣称所有下载已完成。取消/跳过沿用原任务支持能力；任务进行时关闭窗口会要求等待或先取消。

包 URL 缺失或非法时，点击「下载游戏」打开配置对话框，提供包 URL 和两个已有镜像配置项，空值显示示例占位提示；首页无常驻设置入口。远端 URL 要求 HTTPS，本机测试允许 localhost HTTP。镜像为空使用原来源，**镜像设置全局生效**。详情见 [copyparty镜像准备](copyparty镜像准备.md)。自定义可配置 URL 不自动取得可信来源豁免，Prism 的外部文件确认仍保留；正式固定发布源后如需豁免，另行明确来源范围。

内置官方中文翻译和最小翻译索引，仅在数据目录中缺失相应文件时复制；已有文件不会被覆盖，之后仍使用原翻译更新流程。标题字体无需玩家另外安装。

新增持久设置：

| 键 | 含义 |
| --- | --- |
| `NiijimaHomeEnabled` | 默认 true；false 回到原入口 |
| `NiijimaPackUrl` | 包下载 URL，当前为空 |

| `NiijimaDefaultsApplied` | 首次预设已应用 |

外部 URL 导入和命令行指定实例继续走原入口；窗口关闭时计数一并维护。启动控制器和更新器的父窗口改用 QPointer，避免关闭开屏后残留无效窗口指针。

## 2026-10-29 确定版背景与磨砂玻璃

用户批准将已预览的确定版用于启动器，并要求前方叠加磨砂层。内置资源 `launcher/resources/niijima/home-background.png` 是桌面确定版的原样副本（2559×1439），通过 `niijima.qrc` 随程序发布；没有使用 imagegen 图片，也没有改动桌面原图或确定版。

绘制顺序：背景预先模糊 → 按主体区域等比居中裁切 → 浅色半透明磨砂层 → 左侧及底部的对比度渐变 → 清晰的文字和控件。Qt `QGraphicsBlurEffect` 使用 QualityHint，源图尺寸下半径 20（初版为 22，按后续反馈略减弱）；模糊结果在进程内缓存，不在每次重绘或缩放时重复处理。效果仅针对内置背景图，不依赖 Windows 桌面模糊或透明窗口后方内容。

保留橙色标题栏及主要按钮；主体文字改为暖白，次要按钮使用半透明深色底和细边框。相关样式限定在 `homeBody`，设置对话框保留原来的浅色样式。实际窗口及高 DPI 视觉验收继续等待用户允许显示界面。

本轮结果（2026-10-29）：Release 增量编译及 `cmake --install` 均成功（退出码 0），产物 `install/prismlauncher.exe` 已更新；`git diff --check` 通过，内置背景与桌面确定版 SHA-256 相同。未启动 GUI，未重跑与本次视觉改动无关的功能测试。所有修改仍未提交、未推送。
