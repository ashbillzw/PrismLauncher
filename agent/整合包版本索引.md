```json
{
  "1": {
    "version": "1.6",
    "file": "新岛铁道 v1.6.zip"
  }
}
```

JSON 对象的键必须是字符串。ID 是无前导零的十进制正整数，程序转换成 `quint64` 后比较；默认取最大 ID，所以 `"10"` 大于 `"2"`。`version` 是版本说明，既不作字典排序，也不用于替代 ID。`file` 是同目录内的实际文件名，支持中文和空格；程序会进行 URL 编码，维护者不应手动把名字写成百分号转义。记录不能把 `file` 写成绝对 URL 或跨目录路径。

以后可在同一对象内增加 `"2"`、`"3"` 等条目并保留历史版本。先完整上传新 ZIP，再发布更新后的 JSON，避免索引指向尚未完成的文件。

## 启动器行为与可选配置

新岛品牌默认读取 `https://files.yake.wang:25572/%E5%88%9B%E4%B8%96%E7%BA%AA%E7%BD%91%E7%9B%98/minecraft/niijima-launcher/packs/latest.json`。点击“下载游戏”读取索引、选择版本，然后复用原 `InstanceImportTask` 导入；当前已安装实例的“启动游戏”仍直接启动，不新增自动更新流程。不会因缺信息弹出配置或版本选择窗口。

配置在实际数据目录的 `niijimalauncher.cfg`（常规安装为 `%APPDATA%/NiijimaLauncher/niijimalauncher.cfg`）：

| 键 | 默认与行为 |
| --- | --- |
| `NiijimaPackIndexUrl` | 缺失或空时使用上述内置地址；有效自定义值可改索引来源 |
| `NiijimaPackVersionId` | 缺失或空时选择最大 ID；例如 `1` 固定选 ID 1，不存在或格式错误则在现有状态区报错 |
| `NiijimaPackUrl` | 保留既有直接 ZIP URL 覆盖；非空时优先于索引和 ID。空值走索引，不再触发弹窗 |

非空但非法的自定义 URL 不静默替换成另一来源；索引请求、解析及指定 ID 错误均走现有状态/详情行。请求可取消，失败不添加新的询问或重试窗口。原 Prism 安装、账号和文件来源确认机制保持原流程。
